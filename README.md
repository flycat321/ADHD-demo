# ADHD助手应用

一个为ADHD患者定制的全面支持应用，通过科学的任务分解、个性化工具和创新的用户体验，帮助用户提高执行力和专注度。

## 项目概述

本应用旨在为ADHD（注意力缺陷多动障碍）患者提供全方位的支持，包括科学知识库、个人化任务管理、专注工具、社区交流、行为分析等功能模块。应用基于最新的认知科学研究成果，针对ADHD患者的特点量身定制，帮助减轻ADHD对生活的负面影响。

## 核心功能

- **科学知识库**：提供ADHD相关的科学介绍、研究论文和视频讲解
- **身份标签分组**：基于身份标签（如学生、专业人士、创意工作者等）的社群小圈子
- **专业顾问支持**：由专业顾问提供建议和指导
- **行为分析和干预**：分析用户行为模式并提供有效干预策略
- **个人化任务推荐**：智能推荐适合用户特点的任务和活动
- **专注工具**：帮助用户集中注意力的专注计时器和奖励机制
- **社区交流**：用户可分享心得和互相支持的社区平台

## 技术栈

- **前端**：React, TypeScript, Tailwind CSS, shadcn/ui
- **后端**：Node.js, Express
- **数据库**：PostgreSQL, Drizzle ORM
- **认证**：Passport.js, session-based authentication
- **状态管理**：React Query, Zustand
